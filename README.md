### What I learned

I learned how to handle an image's aspect ratio using object-fit to ensure the subject's face remains visible regardless of the image dimensions or position.

Additionally, I learned the importance of visible outline styles for focused elements to improve accessibility (a11y) for keyboard users.

```css
ul a:focus {
  outline: 2px solid var(--green);
  outline-offset: 3px;
}
```
